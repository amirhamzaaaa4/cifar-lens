Small images. A complete experiment.

01

Learn

ResNet20 learns from CIFAR-10 using training-only random crop, flip and Cutout. Label smoothing reduces overconfident training targets.

02

Measure

A separate validation split selects the checkpoint and calibrates confidence. The official test set measures performance after selection.

03

Explain

Grad-CAM highlights regions supporting the original-view prediction. Scores average original and mirrored logits before calibration.

Privacy by design

The model runs in your browser. Uploaded images are never sent to a prediction server or saved by this application. The hosting service and script CDN still receive ordinary page requests.

Know its limits

Only ten classes and 32 × 32 pixels. Every photo is assigned to a class; there is no unknown-object detector. Browser and Python image resizing can differ slightly for uploaded photos. Heatmaps are coarse and do not establish causation. This demo is not for consequential decisions.
